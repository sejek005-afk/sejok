# آزمون‌های ایشیم

```
node tests/run.js
```

- بدون وابستگی؛ فقط Node.js (نسخه ۱۸ به بالا) لازم است.
- `harness.js` فایل‌های `app/src/main/assets/*.js` را در `vm` با شبیه‌ساز `window`/`document`/`localStorage` اجرا می‌کند.
- `dataset.js` داده بزرگ آزمایشی (۱۰هزار پیشرفت/تراکنش/فاکتور/یادداشت، ۳۶٫۵هزار حضور) می‌سازد.
- `reference.js` نسخه قدیمی و ساده‌ی `agg()` برای مقایسه با نسخه سریع است.
- سقف زمان هر صفحه با متغیر `PERF_BUDGET_MS` قابل تغییر است (پیش‌فرض ۴۰۰ میلی‌ثانیه در vm نود که از مرورگر کندتر است).
